# Expert's Modules — Content Rules

1. Create original explanations only.
2. Analyse teaching approaches, sequencing, examples, misconceptions and revision strategies.
3. Never reproduce tutor/platform notes, scripts, PDFs or distinctive wording.
4. Every module must map to a board + subject + chapter.
5. Support English, Hindi and Hinglish where applicable.
6. Keep expert-derived insights separate from official syllabus facts.
7. Store source metadata for internal verification.
8. Target 50–100 useful notes per chapter across the complete chapter ecosystem; never add filler.
