# HISTORY CONTENT AUTHORING RULES

Target:
Class 10 Uttarakhand Board (UBSE), session 2026-27.

Language:
- Student-facing study material: clear Hindi.
- Keep universally used academic terms in English/Hinglish only when
  Hindi would reduce clarity.
- Do not use unnecessarily difficult Hindi.

SOURCE PRIORITY:
1. Official UBSE 2026-27 syllabus.
2. Official UBSE question-bank / sample-paper / paper-design material.
3. NCERT prescribed material where applicable.
4. Other reputable educational references only for cross-checking.

CONTENT RULES:
- Do not copy long passages from any source.
- Rewrite concepts in original, concise language.
- Never invent facts, dates, marks, PYQs or syllabus topics.
- Clearly separate verified PYQs from board-aligned practice questions.
- Avoid duplicate questions.
- Every question must map to a chapter/topic.
- Every answer must be factually checked.
- Explanations should teach, not merely reveal the answer.

QUALITY TARGET:
The material should feel like refined topper notes:
- exam-oriented
- conceptually clear
- easy to revise
- complete enough for board preparation
- concise enough for repeated revision

QUESTION COVERAGE:
Include appropriate examples of:
- MCQ
- very short answer
- short answer
- long answer
- competency/application
- case/source-based
- assertion-reason where relevant
- map/date/fact-based questions where relevant

Do not manufacture a question type merely to fill a quota.

FLASHCARDS:
Each card must test one useful fact/concept only.

DATES:
Only include historically meaningful dates that are relevant to
the prescribed chapter and examination preparation.

PYQ POLICY:
Only label a question PYQ if its source and year are verified.
Otherwise label it as "board-aligned practice".

MARKS:
Do not guess marks distribution for an individual question.
Use official UBSE paper-design/sample-paper evidence when available.
